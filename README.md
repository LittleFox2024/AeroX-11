# AeroX-11
Vista and 8.1 themes for Windows 11

Aero10.1 has been released... but it only include a Windows 7 theme. Aero11 is as of now more or less discontinued. So this is a revival of the Vista and 8.1 themes included in Aero11. This will basically be more updates for the last version offered by Sand216, at least until Aero10.1 includes these themes.

Original theme: [https://github.com/Sand216/Aero11/tree/aero11_seven](https://github.com/Sand216/Aero11/tree/aero11_seven)

Aero10: [https://github.com/vaporvance/aero10](https://github.com/vaporvance/aero10)


*This is not a revival of Aero7-11. That is still discontinued for now.*
